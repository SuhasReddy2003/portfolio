# Suhas Reddy — Portfolio

Personal portfolio site built with Next.js App Router, TypeScript, and Tailwind CSS.

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React (icons)

## Getting started
```bash
npm install
npm run dev
```

## Before deploying
1. Add your resume PDF at `public/resume.pdf`.
2. Update the placeholder URLs (LinkedIn, email) in:
   - `src/components/navbar.tsx`
   - `src/components/hero.tsx`
   - `src/components/contact.tsx`
3. `npm run build` to verify a clean production build.

## Deploy
Push to GitHub, then import the repo at https://vercel.com/new.
